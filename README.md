# Pulso Valparaíso — sitio web

Página del centro de estudios de opinión pública Pulso Valparaíso.

## Qué hay en esta carpeta

| Archivo | Para qué sirve |
|---|---|
| `index.html` | Página de inicio |
| `panel-ciudadano.html` | Inscripción al panel ciudadano (el formulario está en Tally: https://tally.so/r/OQ4Y7K) |
| `css/estilos.css` | Colores, letras y diseño de todo el sitio |
| `js/sitio.js` | Menú para celulares y comportamiento de los formularios |
| `img/favicon.svg` | Ícono que aparece en la pestaña del navegador |

## Cómo cambiar un texto

1. En GitHub, abre el archivo (por ejemplo `index.html`).
2. Haz clic en el lápiz ✏️ ("Edit this file").
3. Busca el texto que quieres cambiar (los textos por completar están entre [corchetes]).
4. Cámbialo y presiona **Commit changes**. En uno o dos minutos la página publicada se actualiza.
